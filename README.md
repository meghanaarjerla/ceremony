# Seemantham Ceremony Website

A beautiful, elegant website for the Seemantham Ceremony invitation of Prabhasree & Bhanuchandar, welcoming their little one.

## Features

✨ **Elegant Design**
- Purple and white color scheme with floral decorations
- Responsive design that works on all devices
- Beautiful typography and spacing

⏰ **Live Countdown Timer**
- Real-time countdown to the event
- Shows days, hours, minutes, and seconds
- Automatically updates every second

📍 **Venue Navigation**
- "View Venue on Maps" button
- Opens Google Maps with the venue location
- Displays: VR Function Hall, Chanukya Nagar, Chinnamushidiwada, Pendurthi

📅 **Save the Date**
- "Save the Date" button downloads an .ics calendar file
- Compatible with all major calendar applications (Google Calendar, Outlook, Apple Calendar, etc.)
- One-click event addition to your calendar

## Files

- `index.html` - Main HTML structure
- `styles.css` - Complete styling and responsive design
- `script.js` - Countdown timer and button functionality

## Usage

1. Open `index.html` in a web browser
2. The countdown timer will automatically start
3. Click "View Venue on Maps" to see the location on Google Maps
4. Click "Save the Date" to download the event to your calendar

## Browser Compatibility

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Mobile browsers

## Customization

You can easily customize:
- Event date and time in `script.js`
- Venue location and coordinates
- Colors and fonts in `styles.css`
- Text content in `index.html`
